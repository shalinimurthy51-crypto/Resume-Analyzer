# AI Resume Analyzer

An AI-powered application that analyzes resumes against job descriptions and provides insights on candidate-job fit.

## Overview

The AI Resume Analyzer helps evaluate how well a resume matches a specific job description. It uses a Large Language Model (LLM) to analyze both documents and provide useful insights such as match percentage and improvement suggestions.

This project demonstrates the practical use of Generative AI in recruitment and resume screening.

## Features

- Upload resume for analysis
- Compare resume with job description
- Calculate resume-job match percentage
- Predict shortlisting probability (Yes / Maybe / No)
- Suggest improvements to make resume ATS-friendly

## Technologies Used

- Python
- Groq API
- Natural Language Processing
- LLM-based analysis

## How It Works

1. User uploads a resume.
2. User provides a job description.
3. The system processes both inputs.
4. The LLM analyzes the content and generates:
   - Match percentage
   - Shortlisting prediction
   - Suggestions for improvement.
